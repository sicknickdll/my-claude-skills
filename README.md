# my-claude-skills

Personal collection of Claude Code skills, organized by category under `.claude/skills/`.

| Category | Skill | Description |
|---|---|---|
| `video-editing/` | `code-motion-studio` | Motion design and animated video made in code, rendered to MP4 |
| `web-design/` | `clone-website` | Rebuild existing websites as working Next.js code (from [JCodesMore/ai-website-cloner-template](https://github.com/JCodesMore/ai-website-cloner-template), MIT) |

Note: Claude Code discovers skills at `.claude/skills/<name>/SKILL.md`. With the category
subfolders, copy or symlink a skill folder to `~/.claude/skills/<name>` to activate it.
